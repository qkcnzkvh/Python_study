# 파이썬
프로그래밍 언어 중 1가지로 웹 크롤링, 금융 분석, 머신러닝, AI, 데이터 분석 등을 이용

## 파이썬 기초
### 변수란?
- 값을 가르키는 이름을 뜻 함 (변수명 = 값)
- PEP8이란 변수 명명 규칙을 따른다.
  단어는 소문자로, 단어 연결은 _ 로, 변수명은 숫자로, 등

TIP. 출력시 f-string 표기하는 것이 깔끔

### 데이터 타입?
- int
  - 숫자형을 말함. 그 중 정수 부분

- float
  - 숫자형 중에 실수나 소수를 뜻함 (정밀한 숫자를 사용할 때 사용됨)

- str
  - 문자형을 말함. ""로 감싸진 모든 것들, +로 합치기가 가능하다

- bool
  - 참과 거짓 두 가지 타입을 가지는 타입으로 조건 판단에 사용된다.
  - 참고 메서드. is_, has_

### 연산자란?
값을 계산하거나 비교할 때 사용하는 기호

- 산술 연산자
  - -,+ 는 그대로 | * 곱셈, | / 나누기 | // 나누고 몫 값만 표시 | ** 거듭제곱 | % 나누고 나머지 값
    
- 비교 연산자
  - == 같은가요 | != 다른가요
    
- 논리 연산자
  - and | or | not
    
- 복합 대입 연산자
  - 산술 연산과 대입을 한번에 처리하는 연산자
  - total = total + 1 -> total += 1    
  - %d 십진수 표현 | %s 문자열 전체를 넣을 때 사용하는 지정 코드
  - %c 문자 1개를 넣을 때 사용 | %f 실수를 넣을 때 사용하는 지정 코드
