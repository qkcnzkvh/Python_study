# 제어문
## 조건문
주어진 조건에 따라 코드를 실행하는 제어문

in
자료 구조 안에 있는지 판별

is
두 값이 같은 개체인지 판별

if
조건에 맞는 것을 판별
기본 구조
    if 조건:
        실행문    # 조건1에 True이면 실행
    elif 조건:   
        실행문    # 조건2에 True이면 실행
    else:       # 그 외 나머지 실행

내용을 추후 작성 시 pass를 사용하여 넘길 수 있다

삼황 연산자 구조
참일때 값 - if - 조건 - else - 거짓일때 값
example = “발열” if body_temp ≥ 37.5 else “정상”

## 반복문
같은 작업을 여러 번 반복해서 실행하게 만드는 제어문

for
정해진 횟수만큼 또는 시퀀스 순서대로 처리

기본 구조
for 변수명 in 자료 변수:
    원하는 코드

while 
조건이 True일 경우 반복 실행

기본 구조
while 조건:
    실행할 코드

    break 반복문 완전히 종료

    continue 현재 반복문을 건너뛰고 다음 반복문으로 진행

List Comprehension 구조
for 반복문을 한 줄로 압축해서 새 리스트로 만드는 방식
[표현식 - for - 변수 - in - 반복가능개체 - (if 조건)]
