## 1. 파이썬 돌아보기

### 1.1 내장 함수

파이썬에서 기본적으로 제공하는 함수로, 별도의 설치 없이 사용할 수 있다.

| 함수 | 역할 |
|---|---|
| `sum()` | 데이터의 합계 |
| `len()` | 데이터의 개수 |

### 1.2 나누기 3종류

| 연산자 | 의미 | 예시 |
|---|---|---|
| `/` | 일반 나누기 | `7 / 3 = 2.333...` |
| `//` | 몫 나누기 | `7 // 3 = 2` |
| `%` | 나머지 나누기 | `7 % 3 = 1` |

### 1.3 딕셔너리

- `keys()` : 키만 가져오기
- `values()` : 값만 가져오기
- 딕셔너리에 존재하지 않는 키를 지정하면 새로운 항목이 추가된다.
- 이미 존재하는 키를 지정하면 해당 값이 수정된다.

```python
patient = {"name": "Alex", "age": 30}

patient["age"] = 31  # 기존 값 수정
patient["gender"] = "M"  # 새로운 항목 추가
```

### 1.4 의학 데이터 분석 시 주의점

일반적인 데이터와 달리 의학 데이터는 위험한 상황을 유추하는 것이 중요하다.

예를 들어, 단순히 환자의 수를 파악하는 것뿐만 아니라 특정 질환의 발생 비율이나 위험군의 특성을 분석할 수 있어야 한다.

## 2. 환자 수와 데이터 유형

### 2.1 환자 수 찾기

- `len()` : 전체 데이터의 개수 확인
- `[]` : 인덱스 번호를 이용하여 특정 데이터에 접근
- 인덱스는 0부터 시작한다.

```python
patients = ["A", "B", "C"]

print(len(patients))  # 3
print(patients[0])    # A
```

### 2.2 데이터 분류

0과 1로 구분된 데이터는 비율을 이용하여 분석하는 경우가 많다.

데이터를 나눌 때는 큰 카테고리부터 구분하는 것이 좋다.

예시: 성별(2가지) → 나이

| 데이터 유형 | 의미 | 예시 |
|---|---|---|
| 식별자 | 데이터를 고유하게 구별하는 값 | 환자 ID |
| 이산형 | 셀 수 있는 개별적인 값 | 환자 수, 방문 횟수 |
| 명목형 | 이름이나 범주로 구분하는 값 | 성별, 혈액형 |
| 연속형 | 일정한 범위에서 연속적인 값을 가질 수 있는 데이터 | 키, 혈압, 체중 |

**TIP.** 머신러닝에서는 데이터 유형을 구분하는 것이 중요하다. 데이터 유형에 따라 전처리와 분석 방법이 달라진다.

## 3. 비율, 백분율, 파생지표

### 3.1 비율과 백분율

비율은 전체에서 특정 조건을 만족하는 데이터가 차지하는 정도이다.

\[
\text{비율} = \frac{\text{조건을 만족하는 수}}{\text{전체 수}}
\]

\[
\text{백분율} = \text{비율} \times 100
\]

### 3.2 증감률

기준값에 비해 변경값이 얼마나 증가하거나 감소했는지를 나타낸다.

\[
\text{증감률} = \frac{\text{변경값} - \text{기준값}}{\text{기준값}} \times 100
\]

### 3.3 BMI (체질량지수)

체중과 키를 이용하여 계산하는 파생지표이다.

\[
BMI = \frac{\text{체중(kg)}}{\text{키(m)}^2}
\]

- 파생변수: 기존의 데이터를 이용하여 새롭게 만든 값
- BMI는 체중과 키라는 기존 데이터를 이용하여 계산한 파생변수이다.

## 4. 평균, 중앙값, 최빈값

### 4.1 평균 (Mean)

모든 데이터의 값을 더한 뒤 데이터의 개수로 나눈 값이다.

\[
\text{평균} = \frac{\text{전체 데이터의 합}}{\text{데이터 개수}}
\]

### 4.2 중앙값 (Median)

데이터를 크기순으로 정렬했을 때 정중앙에 위치하는 값이다.

극단적인 값의 영향을 평균보다 적게 받는다.

- 홀수 개: 가운데 위치한 값
- 짝수 개: 가운데 두 값의 평균

### 4.3 최빈값 (Mode)

데이터에서 가장 많이 등장하는 값이다.

여러 개의 최빈값이 존재할 수 있다.

### 4.4 파이썬으로 구하기

```python
import statistics as stats

print("평균:", stats.mean(bp_values))
print("중앙값:", stats.median(bp_values))
print("최빈값 후보:", stats.multimode(bp_values))
```

**TIP.** `변수 % 2 == 1`은 변수가 홀수인지 확인하는 조건이다. 나머지가 0이면 짝수이다.

---

## 5. 범위, 분산, 표준편차

### 5.1 편차

각 데이터가 평균으로부터 얼마나 떨어져 있는지를 나타낸다.

\[
\text{편차} = \text{데이터 값} - \text{평균}
\]

### 5.2 범위 (Range)

데이터의 최댓값과 최솟값의 차이이다.

\[
\text{범위} = \text{최댓값} - \text{최솟값}
\]

### 5.3 분산 (Variance)

데이터가 평균을 기준으로 얼마나 흩어져 있는지를 나타내는 값이다.

편차를 제곱한 뒤 평균을 구하여 계산한다.

### 5.4 표준편차 (Standard Deviation)

평균을 기준으로 데이터가 얼마나 흩어져 있는지를 나타내는 지표이다.

- 표준편차가 크다 → 데이터가 평균 주변에 넓게 흩어져 있다.
- 표준편차가 작다 → 데이터가 평균 주변에 모여 있다.

분산을 구한 뒤 제곱근을 취하면 표준편차가 된다.

### 5.5 모집단과 표본의 표준편차

| 함수 | 의미 | 사용 상황 |
|---|---|---|
| `stats.pstdev()` | 모집단 표준편차 | 분석 대상 전체 데이터를 가지고 있을 때 |
| `stats.stdev()` | 표본 표준편차 | 일부 표본으로 전체 모집단을 추정할 때 |

표본 표준편차는 표본을 이용해 모집단의 특성을 추정하는 데 사용된다.

## 6. 사분위수와 IQR

### 6.1 사분위수 (Quartile)

데이터를 크기순으로 정렬하여 4개의 동일한 비율로 나눈 기준값이다.

| 구분 | 의미 |
|---|---|
| Q1 | 제1사분위수, 하위 25% 지점 |
| Q2 | 제2사분위수, 중앙값 |
| Q3 | 제3사분위수, 하위 75% 지점 |

### 6.2 IQR (사분위 범위)

Q3와 Q1의 차이로, 가운데 50% 데이터가 분포하는 범위를 나타낸다.

\[
IQR = Q3 - Q1
\]

### 6.3 파이썬으로 사분위수 구하기

```python
import statistics

q1, q2, q3 = statistics.quantiles(
    blood_pressure,
    n=4,
    method="inclusive"
)
```

- `blood_pressure` : 분석할 데이터
- `n=4` : 데이터를 4개의 구간으로 나눔
- `method="inclusive"` : 사분위수를 계산하는 방식

---

## 7. 이상치 계산 및 분리

### 7.1 이상치 기준

IQR을 이용하여 이상치의 하한과 상한을 계산한다.

\[
\text{이상치 하한} = Q1 - 1.5 \times IQR
\]

\[
\text{이상치 상한} = Q3 + 1.5 \times IQR
\]

하한보다 작거나 상한보다 큰 데이터는 이상치로 분류한다.

### 7.2 정상 범위 데이터와 이상치 분리하기

```python
normal_values = [
    value for value in blood_pressure
    if lower_bound <= value <= upper_bound
]

outlier_values = [
    value for value in blood_pressure
    if value < lower_bound or value > upper_bound
]
```

- `normal_values` : 정상 범위에 포함되는 데이터
- `outlier_values` : 이상치로 분류되는 데이터

**주의.** 통계적으로 이상치라고 해서 반드시 오류이거나 비정상적인 환자 데이터인 것은 아니다. 의학 데이터에서는 실제 위험 신호일 수도 있으므로 확인이 필요하다.

## 9. 분포의 이해

### 9.1 빈도 (Frequency)

특정 항목이나 사건이 발생한 횟수이다.

### 9.2 상대빈도 (Relative Frequency)

전체 데이터에서 특정 항목이나 계급이 차지하는 비율이다.

\[
\text{상대빈도} = \frac{\text{특정 항목의 빈도}}{\text{전체 빈도의 합}}
\]

### 9.3 조건부 비율과 조건부 확률

특정 조건 B를 만족하는 경우 중에서 조건 A도 만족하는 비율이다.

\[
P(A \mid B) = \frac{P(A \cap B)}{P(B)}
\]

- \(P(A \mid B)\) : B를 만족하는 상황에서 A가 발생할 확률
- \(P(A \cap B)\) : A와 B를 모두 만족하는 경우의 확률

예시: 특정 질환을 가진 환자 중에서 고혈압도 있는 환자의 비율

## 10. Z-score (표준점수)

### 10.1 개념

Z-score는 특정 데이터가 평균으로부터 표준편차 몇 개만큼 떨어져 있는지를 나타내는 값이다.

표준점수, 표준화 점수, Z값, Z점수라고도 한다.

\[
z = \frac{\text{데이터 값} - \text{평균}}{\text{표준편차}}
\]

### 10.2 해석 방법

평균의 위치를 0으로 설정하여 해석한다.

| Z-score | 의미 |
|---|---|
| z > 0 | 데이터가 평균보다 큼 |
| z = 0 | 데이터가 평균과 같음 |
| z < 0 | 데이터가 평균보다 작음 |

### 10.3 68-95-99.7 규칙

정규분포를 따르는 데이터에서는 다음과 같은 비율이 성립한다.

| 범위 | 포함되는 데이터 비율 |
|---|---|
| 평균 ± 표준편차 1개 (z: -1~1) | 약 68% |
| 평균 ± 표준편차 2개 (z: -2~2) | 약 95% |
| 평균 ± 표준편차 3개 (z: -3~3) | 약 99.7% |

### 10.4 표준화 (Standardization)

데이터를 Z-score로 변환하는 과정이다.

- 데이터의 크기나 단위가 서로 다르면 직접 비교하기 어렵다.
- 표준화를 통해 서로 다른 데이터의 상대적인 위치를 비교할 수 있다.
- 선형 표준화는 데이터의 분포 모양을 바꾸지 않는다.

### 10.5 최소-최대 정규화 (Min-Max Normalization)

데이터의 최솟값을 0, 최댓값을 1로 변환하는 방법이다.

\[
x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
\]

## 11. 공분산과 상관계수

### 11.1 두 변수의 관계

두 데이터가 함께 변하는 모습을 의미한다.

| 관계 | 의미 |
|---|---|
| 양의 관계 | 한 변수가 증가하면 다른 변수도 증가하는 경향 |
| 음의 관계 | 한 변수가 증가하면 다른 변수는 감소하는 경향 |
| 관계 없음 | 한 변수가 변해도 다른 변수와 일정한 관계가 나타나지 않음 |

### 11.2 공분산 (Covariance)

두 변수가 각자의 평균을 기준으로 같은 방향 또는 반대 방향으로 움직이는지를 나타내는 값이다.

- 공분산이 양수 → 두 변수가 같은 방향으로 움직이는 경향
- 공분산이 음수 → 두 변수가 반대 방향으로 움직이는 경향

**문제점**

- 관계가 얼마나 강한지는 직접적으로 알기 어렵다.
- 데이터의 단위와 크기에 따라 값이 달라진다.

### 11.3 상관계수 (Correlation Coefficient)

두 변수 사이의 관계가 어느 방향으로 얼마나 강하게 나타나는지를 나타내는 지표이다.

상관계수는 -1에서 1 사이의 값을 가진다.

\[
-1 \leq r \leq 1
\]

| 상관계수의 절댓값 | 관계의 강도 |
|---|---|
| 0.0~0.2 | 거의 관계 없음 |
| 0.2~0.4 | 약한 관계 |
| 0.4~0.6 | 보통 수준의 관계 |
| 0.6~0.8 | 강한 관계 |
| 0.8~1.0 | 매우 강한 관계 |

- 부호 (+, -) : 관계의 방향
- 절댓값 : 관계의 강도

※ 위 구간은 일반적인 해석 예시이며, 분야와 상황에 따라 기준이 달라질 수 있다.

### 11.4 상관관계와 인과관계

상관관계가 있다고 해서 반드시 원인과 결과 관계가 성립하는 것은 아니다.

예시: 아이스크림 판매량과 익사 사고

두 변수 사이에 양의 상관관계가 나타날 수 있지만, 아이스크림 판매가 익사 사고의 직접적인 원인이라는 뜻은 아니다.

이때 기온은 두 변수에 영향을 줄 수 있는 제3의 변수인 혼란변수(Confounding Variable)이다.

### 11.5 상관관계 분석 방법

- 피어슨 상관계수 (Pearson Correlation) : 두 변수 사이의 선형 관계를 측정한다.
- 스피어만 상관계수 (Spearman Correlation) : 데이터의 순위를 이용하여 단조 관계를 측정한다.

## 핵심 정리

- 데이터 유형을 정확하게 구분해야 적절한 분석 방법을 선택할 수 있다.
- 평균, 중앙값, 최빈값은 데이터의 중심을 나타내는 대표적인 지표이다.
- 분산과 표준편차는 데이터가 얼마나 흩어져 있는지를 나타낸다.
- 사분위수와 IQR은 데이터의 분포와 이상치를 파악하는 데 사용된다.
- Z-score는 서로 다른 데이터의 상대적인 위치를 비교할 때 유용하다.
- 공분산과 상관계수는 두 변수 사이의 관계를 수치로 표현한다.
- 상관관계는 인과관계를 의미하지 않는다.
- 의학 데이터 분석에서는 이상치나 특정 비율이 실제 위험 신호일 수 있으므로 맥락을 함께 고려해야 한다.
