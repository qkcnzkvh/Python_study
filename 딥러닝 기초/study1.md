1. CRISP-DM (데이터 분석 및 AI 프로젝트 방법론)
CRISP-DM(Cross Industry Standard Process for Data Mining)은 데이터를 기반으로 비즈니스 문제를 해결하기 위한 표준적인 데이터 분석 방법론이다.

총 6단계로 구성된다.
1-1. 비즈니스 이해 (Business Understanding)
- 해결해야 할 문제가 무엇인지 정의
- 데이터 분석의 방향과 목표 설정
- Feature(피처): 모델에 입력할 데이터
- Target(타겟): 모델이 예측할 정답
1-2. 데이터 이해 (Data Understanding)
- 원본 데이터 확인
- 각 컬럼에 어떤 정보가 있는지 파악
- 데이터 구조 및 특성 확인
- EDA(탐색적 데이터 분석), CDA(확증적 데이터 분석) 등 수행
- Pandas, NumPy 등을 활용한 데이터 분석
1-3. 데이터 준비 (Data Preparation)
- 모델 학습에 적합한 데이터 구조 생성
- 결측치 처리
- 이상치 확인 및 처리
- 데이터 변환 및 정규화
- 학습 및 평가 데이터 분할
1-4. 모델링 (Modeling)
- 문제에 적합한 모델 선정
- 모델 학습
- 하이퍼파라미터 조정
- 모델 성능 검증
1-5. 평가 (Evaluation)
- 모델이 비즈니스 문제를 해결했는지 확인
- 정확도 및 성능 평가
- 실제 활용 가능성 검토
1-6. 배포 (Deployment)
- 완성된 모델을 실제 서비스에 적용
- 사용자에게 예측 결과 제공
- 운영 및 성능 모니터링

2-3. 학습
- 데이터를 모델에 입력
- 예측값 계산
- 손실값 계산
- 역전파를 통한 기울기 계산
- Optimizer를 통한 가중치 업데이트
- 학습 곡선 확인
2-4. 예측 및 평가
- 테스트 데이터 예측

- 평가 지표를 통한 모델 성능 확인
3. Tensor (텐서)
Tensor는 숫자를 여러 차원으로 묶어 표현하는 데이터 구조이다.

PyTorch에서는 딥러닝 모델의 입력 데이터와 계산 결과를 Tensor 형태로 처리한다.
Tensor의 차원
차원	명칭	설명	예시
0차원	Scalar	하나의 숫자	5
1차원	Vector	숫자의 나열	[1, 2, 3]
2차원	Matrix	행과 열로 구성된 행렬	[[1, 2], [3, 4]]
3차원	3-way Tensor	3개의 축을 가진 데이터	이미지의 채널·높이·너비
4차원	4-way Tensor	4개의 축을 가진 데이터	이미지 배치 데이터

4. PyTorch (파이토치)
PyTorch는 딥러닝 모델을 개발하고 학습시키기 위한 오픈소스 프레임워크이다.
주요 특징
1. GPU 사용 가능: GPU를 활용하여 대량의 행렬 연산을 빠르게 처리할 수 있다.
2. 자동 미분 지원: 역전파에 필요한 기울기를 자동으로 계산한다.
3. 효율적인 메모리 관리: Tensor 연산과 메모리 관리를 지원한다.
4. 유연한 모델 설계: 다양한 신경망 구조를 구현할 수 있다.
PyTorch 데이터 처리 과정

    ↓
Tensor 변환
    ↓
TensorDataset 생성
    ↓
DataLoader 생성
    ↓
모델 학습


구성 요소	역할

DataLoader	데이터를 Batch 단위로 나누어 모델에 전달

5. 딥러닝의 학습 과정
딥러닝은 예측 결과와 실제 정답 사이의 오차를 줄이도록 가중치를 반복적으로 조정하는 과정이다.
기본 학습 순서
1. 가중치 초기화

랜덤한 초기값 설정

2. 예측값 계산

Forward Propagation (순전파)

3. 오차 계산

Loss Function으로 손실값 계산

4. 기울기 계산

Backpropagation (역전파)

5. 가중치 업데이트

Optimizer로 오차 감소

위 과정을 반복하여 학습

5-1. 가중치 (Weight)
가중치는 입력 데이터가 예측 결과에 얼마나 영향을 주는지 나타내는 값이다.

선형 회귀의 기본 형태:
\[
\hat{y}=w_1x_1+w_2x_2+\cdots+w_nx_n+b
\]

- \(x\): 입력 데이터
- \(w\): 가중치
- \(b\): 편향(Bias)
- \(\hat{y}\): 예측값
5-2. Epoch와 Learning Rate
용어	의미
Epoch	전체 학습 데이터를 한 번 학습한 단위
Learning Rate (lr)	가중치를 얼마나 크게 업데이트할지 결정하는 학습률
Batch Size	한 번의 학습 단계에서 사용하는 데이터 개수

예를 들어 학습 데이터가 1,000개이고 Batch Size가 100이라면 한 Epoch에 10번의 Batch 학습이 진행된다.
5-3. Optimizer (최적화 알고리즘)
Optimizer는 손실값을 줄이기 위해 가중치를 업데이트하는 알고리즘이다.

Gradient Descent (경사 하강법)

손실 함수의 기울기를 이용하여 손실값이 작아지는 방향으로 가중치를 조정한다.
\[
W_{new}=W_{old}-lr\times Gradient
\]

- 기울기가 양수이면 가중치를 감소시키는 방향으로 이동
- 기울기가 음수이면 가중치를 증가시키는 방향으로 이동
- 기울기가 0에 가까워지면 최솟값에 도달한 상태일 수 있음

대표 Optimizer: Adam

Adam은 기울기의 평균과 제곱 평균을 활용하여 학습률을 조정하는 최적화 알고리즘이다.

일반적인 경사 하강법보다 학습을 안정적이고 효율적으로 진행하는 데 도움이 된다.
6. 딥러닝 모델의 기본 구조
6-1. 선형 회귀 모델 (Linear Regression)
선형 회귀는 입력 데이터와 출력 데이터 사이의 선형적인 관계를 학습하는 모델이다.
신경망의 기본 구성







mdpi.com


구성 요소	역할
Input Layer	입력 데이터를 전달
Hidden Layer	입력 데이터의 특징을 학습
Output Layer	최종 예측 결과 출력

기본 코드 구조
n_feature = X.shape[1]model = nn.Sequential(    nn.Linear(n_feature, 1)).to(device)loss_fn = nn.MSELoss()optimizer = Adam(model.parameters(), lr=0.1)



- nn.Linear(n_feature, 1): 입력 피처를 받아 출력값 1개 생성
- nn.MSELoss(): 평균 제곱 오차 손실 함수
- Adam(): 가중치 업데이트 알고리즘
- device: CPU 또는 GPU 실행 장치
6-2. 은닉층 (Hidden Layer)
은닉층은 입력 데이터의 특징을 학습하는 중간 계층이다.

은닉층이 여러 개 있어도 활성화 함수가 없다면 전체 계산은 하나의 선형 변환으로 표현될 수 있다.

따라서 복잡한 패턴을 학습하기 위해 활성화 함수를 사용한다.
활성화 함수 (Activation Function)
활성화 함수는 신경망에 비선형성을 추가하여 복잡한 데이터 관계를 학습할 수 있도록 한다.

대표적인 활성화 함수: ReLU
\[
ReLU(x)=\max(0,x)
\]

- 입력값이 0보다 작으면 0
- 입력값이 0보다 크면 입력값 그대로 출력

- 노드가 줄어들면: 정보 압축
- 노드가 늘어나면: 표현 공간 확장
