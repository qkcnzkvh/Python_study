1. 기본 용어
1.1 테뷸러 데이터 (Tabular Data)
- 테이블 구조로 이루어진 데이터
- 예시: Excel, CSV, DB 파일 등
1.2 AI 관련 개념
용어	설명
AI (인공지능)	인간의 지능을 모방하는 가장 광범위한 개념
머신러닝 (Machine Learning)	데이터로부터 규칙과 패턴을 학습하는 과정
딥러닝 (Deep Learning)	인간의 뇌 신경망을 모방한 심층 학습 방식
생성형 AI (Generative AI)	새로운 콘텐츠를 만들어 낼 수 있는 AI

- 생성형 AI는 NLP(자연어 처리) 영역에 딥러닝을 접목한 영역으로 소개됨.

2. AI의 기초
2.1 기호주의 vs 연결주의
기호주의 (Symbolic AI)
- 초기 AI의 생성 방식
- 상황에 맞는 정의를 입력하고, 입력된 정의를 판단하여 답을 도출
- 예외 규칙을 일일이 입력해야 한다는 한계가 있음
연결주의 (Connectionist AI)
- 데이터와 정답 쌍을 제공
- 데이터로부터 스스로 패턴을 발견하도록 학습시키는 방식
2.2 머신러닝과 딥러닝의 차이
Feature (특성)
- 데이터가 가진 특징
- 통계에서는 독립 변수에 해당
- 머신러닝에서는 정답을 예측하기 위해 사용하는 입력 변수
구분	머신러닝	딥러닝
데이터 규모	소~중규모 데이터	대용량 데이터
하드웨어	일반 CPU로 학습 가능	고성능 GPU 등 필요
특징 추출	분석가의 수동 작업 필요	심층 신경망이 자동으로 특징 추출
학습 시간	상대적으로 짧음	상대적으로 오래 걸림

- 머신러닝은 Feature를 직접 입력해야 함.
- 딥러닝은 심층 신경망을 통해 특징을 자동으로 추출하는 방식으로 설명됨.
- 은닉층을 통한 도출 과정이 깊기 때문에 Deep Learning이라고 부름.

3. AI 모델을 만드는 목적
목표: 일반화된 규칙을 찾는 것
3.1 과적합 (Overfitting) 주의
- 주어진 데이터셋에만 과도하게 최적화되는 현상
- 학습 데이터에만 의존적으로 학습하는 상태
- 새로운 데이터에 대한 일반화 성능이 떨어질 수 있음
- 모델이 지나치게 복잡한 경우 발생할 수 있음
3.2 학습이란?
가중치(Weight), 모델 아키텍처(Model Architecture), 편향(Bias) 등을 이용하여 규칙과 패턴을 찾고 최적의 값을 찾아가는 과정이다.
- 가중치 (Weight): 각 특성의 중요도를 반영하는 값
- 모델 아키텍처: 예측을 수행하기 위한 알고리즘 또는 신경망 구조
- 편향 (Bias): 활성화 등을 조절하는 상수값
3.3 데이터 역할 분리
데이터	역할	설명
Training Data	학습용	알고리즘이 정답을 찾도록 만드는 기본 데이터
Validation Data	검증용	중간 성능 평가 및 하이퍼파라미터 조정
Test Data	평가용	학습이 끝난 모델의 객관적인 성능 측정

데이터 분할 비율
- 전통적인 접근법
  - 6 : 2 : 2 (Train : Validation : Test)
  - 8 : 2 (Train : Test)
- 현대적인 접근법
  - 98 : 1 : 1
  - 데이터가 수백만 건 이상으로 충분히 많은 경우 활용

6. 데이터 유출 (Data Leakage)
6.1 개념
모델 학습 과정에서 실제 예측 시점에는 알 수 없는 정보가 훈련 데이터에 포함되는 현상이다.
6.2 문제점
- 모델 성능이 비정상적으로 높게 측정될 수 있음
- 실제 일반화 성능을 잘못 평가하게 됨
- 성능 검증 시 가장 먼저 확인해야 하는 부분 중 하나

7. 데이터 종류
데이터를 받으면 먼저 데이터 유형을 확인하고 적절한 모델을 선택해야 한다.
7.1 범주형 데이터 (Categorical)
범주를 구분하는 데이터이다.
- 이진 분류 (Binary Classification): 0과 1 두 가지 범주 구분
- 다중 분류 (Multi-class Classification): 3개 이상의 범주 구분
예시:
- Pima Indians Dataset
- 임상 데이터를 이용한 당뇨병 발병 여부 예측
7.2 회귀형 데이터 (Regression)
연속적인 수치를 예측하는 데이터이다.
- 수치형 (Continuous): 실수형, 정수형
- 선형 회귀: 결과값을 하나의 직선으로 표현
- 로지스틱 회귀: 확률을 계산한 후 Yes / No 형태로 분류
예시:
- Scikit-learn Diabetes Dataset
- 1년 후 질병 진행도 예측
