시각화 미니 프로젝트 (8.4~8.6)
흡연 여부 데이터 분석 및 시각화 프로젝트
1. 프로젝트 목적
- 지금까지 학습한 데이터 분석 및 시각화 내용을 직접 적용
- 학습 과정에서 부족한 부분 점검
- 실제 데이터를 활용한 분석 경험 쌓기
2. 데이터 설명
신체 및 건강 관련 데이터를 활용하여 흡연 여부와의 관계를 분석한다.
데이터 분류	주요 내용
신체 기본 정보	신체 관련 기본 지표
일반 건강 상태	전반적인 건강 상태
혈압 및 순환계	혈압, 순환계 관련 지표
대사 및 혈당	혈당, 지질 관련 지표
혈액 및 장기 기능	혈액, 신장, 간 기능 관련 지표

3. 개인 분석
5일 점심까지 완료
1. 라이브러리 불러오기
2. 데이터 불러오기
3. 데이터 기본 정보 확인
4. 데이터 분석
5. 분석을 위한 가설 수립
6. 가설을 바탕으로 데이터 분석 및 시각화
4. 팀 분석
6일 오후까지 완료
1. 개인 프로젝트 결과 공유
2. 개인별 분석 결과 비교
3. 분석 결과 종합
4. 팀 단위 분석 및 결론 도출
5. 발표 및 제출
제출 자료
- 개인 분석 파일
- 팀 분석 파일
- 발표 자료 (PPT)
발표 시간

- 20분 이내
6. 프로젝트 진행 시 중요 사항
- 정답이 정해져 있는 프로젝트가 아님
- 분석 결과 자체보다 학습한 내용을 어떻게 활용하는지가 중요
- 데이터를 살펴보고 스스로 가설을 세우는 과정이 중요
- 다양한 분석 방법과 시각화를 활용하여 결과를 해석하는 경험이 중요
핵심: 지금까지 배운 데이터 분석 및 시각화 기법을 실제 데이터에 적용하고, 스스로 분석 방향을 설정하는 실전 프로젝트이다.
