LLaMA와 LLM
LLaMA란?
Large Language Model Meta AI
- Meta에서 공개한 대형 언어 모델
- 다양한 자연어 처리 작업에 활용 가능
Llama 3.2 1B Instruct
- LLaMA 3.2 모델 중 하나
- 약 10억 개의 파라미터를 가진 경량 모델
- Instruct 모델로 사용자 지시를 따르도록 학습됨
LLM 프롬프트의 3가지 구성
1. User Prompt
- 사용자가 입력하는 프롬프트
- AI에게 질문하거나 작업을 요청하는 내용
2. System Prompt
- 개발자가 작성하는 AI의 기본 규칙과 역할 설정
- 응답 방식, 보안, 제한 사항 등을 지정
3. Assistant Message
- AI가 사용자에게 전달하는 응답
- 이전 대화 내용을 함께 관리하면 대화의 흐름을 이어갈 수 있음
학습과 추론
Learning (학습)
- 데이터를 바탕으로 모델의 파라미터를 조정하는 과정
- 데이터의 패턴과 특징을 학습
Inference (추론)
- 학습된 모델을 이용하여 새로운 입력에 대한 결과를 생성하는 과정
- 사용자의 질문에 답변하거나 예측을 수행
대화 기록 관리 방법
LLM은 대화가 길어질수록 입력 토큰이 증가하므로 대화 기록 관리가 중요함.
최근 N개 대화만 사용
- 최근 대화 일부만 모델에 전달하는 방식

장점
- 최근 대화의 맥락을 중요하게 유지
- 입력 토큰 사용량을 제한할 수 있음
단점

- 오래된 대화 내용을 잊을 수 있음
대화 내용 요약 후 저장
- 이전 대화를 요약하여 저장
- 이후 대화에서 요약 내용을 활용
장점
- 오래된 대화의 핵심 내용을 유지
- 전체 대화를 전달하는 것보다 토큰을 절약할 수 있음
단점

- 요약 과정에서 세부 내용이 누락될 수 있음
소프트웨어 설계 원칙
응집도는 높게, 결합도는 낮게
응집도 (Cohesion)
- 하나의 모듈 안에 서로 관련된 기능을 모아두는 정도
- 관련된 기능끼리 모여 있을수록 응집도가 높음
결합도 (Coupling)
- 서로 다른 모듈이 얼마나 의존하고 있는지를 나타내는 정도
- 모듈 간 의존성이 낮을수록 결합도가 낮음
핵심
- 비슷한 역할을 하는 기능은 모아두기
- 서로 다른 기능끼리 지나치게 의존하지 않도록 설계하기

데이터베이스 트랜잭션
트랜잭션 (Transaction)이란?
- 데이터베이스에서 하나 이상의 작업을 하나의 논리적인 작업 단위로 묶는 것
- 여러 작업이 모두 성공하면 확정하고, 중간에 실패하면 전체 작업을 취소할 수 있음
- 일부 작업만 반영되는 문제를 방지
ACID 원칙
A - Atomicity (원자성)
- 모든 작업이 성공하거나 모든 작업이 실패해야 함
- 일부 작업만 실행되는 것을 방지
C - Consistency (일관성)
- 데이터베이스가 정해진 규칙과 제약 조건을 유지해야 함
- 트랜잭션 전후 데이터의 일관성이 유지되어야 함
I - Isolation (고립성)
- 동시에 실행되는 트랜잭션이 서로에게 미치는 영향을 적절히 제어
- 각 트랜잭션이 독립적으로 실행되는 것처럼 보이도록 보장
D - Durability (지속성)

- 커밋된 결과는 장애가 발생하더라도 보존되어야 함

핵심 정리
트랜잭션은 여러 데이터베이스 작업을 하나로 묶어서 성공하면 확정하고, 실패하면 취소하는 것.

Docker
Docker란?
- 애플리케이션과 실행 환경을 함께 묶어서 배포하는 도구
- 개발 환경과 실제 실행 환경의 차이로 발생하는 문제를 줄임
- "내 컴퓨터에서는 되는데요"라는 문제를 해결하기 위한 기술
Docker의 핵심 개념
Image (이미지)
- 컨테이너를 생성하기 위한 설계도
- 애플리케이션 실행에 필요한 파일과 설정을 포함
- 정적인 상태의 파일
Container (컨테이너)
- 이미지를 기반으로 실제 실행되는 독립적인 환경
- 이미지가 실행된 상태
- 동적인 실행 환경
Image와 Container의 관계
- Image: 실행 환경의 설계도
- Container: 이미지를 기반으로 실행된 실제 환경
Dockerfile
Dockerfile이란?
- Docker 이미지를 만들기 위한 설정 파일
- 애플리케이션 실행에 필요한 환경과 명령어를 정의
주요 명령어
1. FROM

- 기반이 되는 이미지를 지정
FROM python:3.13-slim


2. WORKDIR
- 컨테이너 내부에서 작업할 디렉터리를 지정
- 해당 디렉터리가 없으면 생성
WORKDIR /app
