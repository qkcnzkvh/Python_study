1. 컴퓨터 비전 (Computer Vision)
사람이 시각을 통해 사물을 인지하듯이 컴퓨터가 이미지와 영상을 인식, 분석, 판별할 수 있도록 데이터를 처리하는 기술
1-1. 데이터의 종류
정형 데이터 (Structured Data)
- 관계형 데이터베이스 기반
- 데이터 하나가 갖는 정보량이 상대적으로 많음
- 데이터 간의 관계를 수식이나 통계적 방법으로 분석하여 사람이 해석하고 인사이트 도출
- 예시: 환자 정보, 나이, 성별, 진단 결과 등
비정형 데이터 (Unstructured Data)
- 이미지, 영상, 자연어, 소리, 신호 등
- 개별 데이터의 구조가 일정하지 않음
- 데이터 하나만으로는 의미를 파악하기 어려울 수 있음
- 여러 데이터를 모아 패턴을 학습하고 인식, 판별 등의 추론 진행
1-2. 컴퓨터 비전의 6가지 핵심 영역
1. 분류 (Classification)
   - 이미지나 영상을 특정 라벨로 분류
   - 질문: 이 이미지는 무엇을 나타내는가?
   - 예시: X-ray 이미지가 정상인지 폐렴인지 판별
2. 검출 (Object Detection)
   - 이미지 내 특정 객체가 어느 위치에 존재하는지 파악
   - 질문: 이 객체는 이미지 어디에 존재하는가?
   - 예시: X-ray 이미지에서 병변의 위치 탐지
3. 분할 (Segmentation)
   - 이미지 내 특정 객체의 경계를 찾아 영역을 구분
   - 질문: 이 객체는 이미지에서 어느 영역을 차지하는가?
   - 예시: 종양이나 병변의 정확한 영역 추출
4. 추적 (Tracking)
   - 영상 내 시간의 흐름에 따라 특정 객체의 위치를 추적
   - 질문: 시간에 따라 이 객체는 어디로 이동하는가?
   - 예시: 내시경 영상에서 특정 조직의 움직임 추적
5. 정합 (Registration)
   - 서로 다른 시점이나 조건에서 촬영된 이미지의 좌표계를 일치시킴
   - 질문: 서로 다른 시점에서 촬영된 이미지의 동일한 위치는 어디인가?
   - 예시: 수술 전후 MRI 이미지 비교
6. 생성 (Generation)
   - 학습된 데이터를 바탕으로 새로운 텍스트, 이미지, 영상 등을 생성
   - 질문: 학습한 데이터를 바탕으로 새로운 데이터를 생성할 수 있는가?
   - 예시: 의료 영상 생성 및 이미지 복원
1-3. 컴퓨터 비전의 발전 단계
- 2010년 이전: 사람이 직접 특징을 추출하는 수작업 기반 방식
- 2012년: CNN(합성곱 신경망) 등장 및 발전
- 2020년: Vision Transformer(ViT) 등장
- 2023년 이후: Foundation Model(파운데이션 모델) 및 멀티모달 모델 발전

2. 의료 비정형 데이터 모달리티
의료 분야에서 활용되는 대표적인 비정형 데이터의 종류
2-1. X-ray
- 2차원(2D) 이미지
- 데이터가 풍부하고 접근성이 높아 진입하기 쉬움
- 여러 조직이 투영되어 겹쳐 보이기 때문에 미세 병변 구분이 어려움
2-2. CT (Computed Tomography)
- 3차원(3D) 영상 데이터
- 정량적인 밀도 정보를 제공
- Window 설정이 영상의 가시성과 분석 성능에 영향을 줌
정량 밀도 (HU, Hounsfield Unit)
- 인체 조직의 방사선 감쇠 정도를 숫자로 나타내는 표준 단위
- 조직의 밀도 차이를 객관적으로 비교할 수 있음
2-3. MRI (Magnetic Resonance Imaging)
- 촬영 시퀀스에 따라 조직의 대비와 표현이 달라짐
시퀀스	주요 특징
T1	해부학적 구조를 선명하게 확인
T2	수분이 많은 조직 및 병리적 변화 확인
FLAIR	뇌척수액 신호를 억제하여 주변 병변을 선명하게 확인

2-4. Endoscopy (내시경)
- 실시간 영상 데이터
- 프레임 간 연속성이 중요
- 실시간 처리를 위해 지연시간(Latency) 관리가 중요
2-5. Pathology (병리 영상)
- 고해상도 조직 이미지
- 전체 이미지를 작은 패치(Patch) 단위로 분할하여 학습
- 분석 결과를 재조합하여 전체 조직의 특성을 파악

3. CNN 합성곱 신경망
3-1. CNN이란?
CNN (Convolutional Neural Network)

합성곱 연산을 활용하여 이미지와 같은 데이터에서 중요한 특징을 자동으로 추출하는 신경망 알고리즘
- 이미지를 여러 단계에 걸쳐 처리하면서 중요한 특징을 추출
- 일반적으로 공간적 크기를 줄이고 특징 채널을 확장
- 추출한 특징을 활용하여 분류(Classification) 및 회귀(Regression)에 활용
- 이미지 인식과 분석에 주로 사용
3-2. CNN의 주요 구성 요소
① 합성곱 레이어 (Convolution Layer)
이미지의 픽셀값을 필터(Filter)를 이용해 연산하여 특징을 추출하는 계층
- 입력 이미지의 RGB 또는 Grayscale 픽셀값을 활용
- 필터를 통해 이미지의 특징을 추출
- 필터마다 서로 다른 특징을 학습
- 필터 내부의 값은 가중치(Weight)로 작동하며 역전파를 통해 갱신
합성곱 연산 절차
1. Padding
   - 입력 이미지의 가장자리에 값을 추가하는 작업
   - 일반적으로 0으로 채우는 Zero Padding 사용
   - 입력 이미지의 크기를 유지하는 데 활용
2. Filtering
   - 작은 크기의 행렬(Filter)을 활용하여 이미지의 특징 추출
3. Sliding
   - 필터를 이미지 위에서 일정한 간격(Stride)으로 이동시키며 연산 수행
② 풀링 레이어 (Pooling Layer)
앞서 추출한 이미지의 특징이 담긴 행렬(Matrix)의 크기를 축소하는 계층
- 차원 축소(Down Sampling)가 목적
- 데이터 크기를 줄여 연산량 감소
- 중요한 특징을 유지하면서 이미지 크기를 축소
종류
- Max Pooling
  - 주어진 영역(Window) 내에서 가장 큰 값을 선택
  - 경계면, 텍스처 등 강하게 나타나는 특징을 보존
  - 작은 위치 변화에 대한 민감도를 낮춤
- Average Pooling
  - 주어진 영역 내 데이터의 평균값을 계산
  - 이미지의 전반적인 패턴을 반영
  - 세부적인 특징보다 일반적인 정보를 유지할 때 활용
③ 완전 연결 레이어 (Fully Connected Layer)
- 앞선 합성곱 및 풀링 계층에서 추출한 특징을 활용
- 모든 입력 노드와 출력 노드가 연결된 구조
- 추출된 특징을 종합하여 최종 결과를 분류하거나 예측

4. 1일 차 과제 리뷰 및 정형 데이터 분석
4-1. 데이터를 받았을 때 가장 먼저 확인해야 하는 것
정형 데이터의 기본 구조
구분	의미	확인 사항
Index	데이터의 순서	데이터 개수, 관측치
Columns	데이터 항목	데이터 타입, 변수 종류
Values	데이터의 실제 값	데이터 형식, 날짜 형식 등

Index
- 데이터의 순서와 각 행을 구분하는 역할
- 데이터 개수 확인
- 통계적 분석, 가설 검정, 시계열 분석 등에 활용
Columns
- 데이터의 항목 및 변수
- 데이터 타입 확인
- 연속형, 범주형, 순서형 변수 등으로 구분
Values
- 실제 데이터 값
- 값의 형식(Format) 확인
- 날짜, 숫자, 문자열 등의 형태 확인
데이터 병합 시 주의사항
- 데이터가 어떤 방식으로 수집되었는지 확인
- 데이터 간 공통 식별자를 기준으로 병합
- 병합 방식에 따라 데이터가 누락되거나 중복될 수 있음
pd.merge(    df_patient,    df_diagnosis,    on='환자ID',    how='inner')



4-2. 정형 데이터 분석 절차
① 기술적 데이터 분석 (DDA, Descriptive Data Analysis)
- 데이터의 구조 확인
- 데이터 타입 확인
- 기초 통계량 확인
- 목표 변수(Y) 선택
② 탐색적 데이터 분석 (EDA, Exploratory Data Analysis)
- 목표 변수(Y)와 설명 변수(X) 간의 관계 파악
- 데이터의 트렌드 및 경향성 확인
- 데이터 간 상관성, 연관성, 유사성 분석
- 데이터 시각화
- 분석을 통해 가설 수립
③ 확증적 데이터 분석 (CDA, Confirmatory Data Analysis)
- 통계적 가설 검정 수행
- 수립한 가설이 통계적으로 유의한지 검증
- 비즈니스 인사이트 도출
④ 예측적 데이터 분석 (PDA, Predictive Data Analysis)
- 목표 변수(Y)와 설명 변수(X) 간의 관계를 모델링
- 새로운 데이터가 들어왔을 때 목표 변수(Y) 예측
TIP

비정형 데이터는 데이터의 구조와 특성이 다르므로 정형 데이터 분석 절차를 그대로 적용하지 않음.
