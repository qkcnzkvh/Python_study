5. 통계적 가설 검정
5-1. 가설 검정이란?
규명하고자 하는 내용을 가설로 수립하고, 통계적인 방법을 통해 해당 가설이 타당한지 객관적으로 판단하는 작업
5-2. 가설의 종류
① 귀무가설 (Null Hypothesis, H0)
- 현재까지 주장되어 온 내용 또는 기존 상황을 설명하는 가설
- 일반적으로 차이나 변화가 없다는 내용을 가정
- 통계적 검정에서 기본적으로 참이라고 가정하는 가설
예시:
- 두 집단의 평균에는 차이가 없다.
- 두 변수는 서로 독립이다.
- 수집된 표본은 정규분포를 따른다.
② 대립가설 (Alternative Hypothesis, H1)
- 새롭게 주장하는 내용이나 기존과 다른 주장을 설명하는 가설
- 귀무가설과 반대되는 내용
- 연구자가 검증하고자 하는 주장을 반영
예시:
- 두 집단의 평균에는 차이가 있다.
- 두 변수는 서로 연관성이 있다.
- 수집된 표본은 정규분포를 따르지 않는다.
5-3. P-value (유의확률)
- 확률분포를 기반으로 계산되는 값
- 귀무가설이 참이라고 가정했을 때, 관측된 결과와 같거나 더 극단적인 결과가 나올 확률
주의사항
- P-value는 귀무가설이 참일 확률이 아님.
- P-value가 작을수록 귀무가설과 관측된 데이터 사이의 양립 가능성이 낮다고 판단
5-4. 유의수준 (Significance Level)
가설 검정에서 귀무가설을 기각할지 판단하는 기준

- 일반적으로 0.05(5%) 사용
조건	판단
P-value > 0.05	귀무가설 기각 실패
P-value < 0.05	귀무가설 기각

※ P-value와 유의수준이 같은 경우에는 사전에 정한 검정 기준에 따라 판단함.
5-5. 가설 검정 기법의 종류
① 단일 변수 분석
연속형 변수: 정규성 검정

데이터가 정규분포를 따르는지 확인
- 귀무가설(H0): 해당 연속형 자료는 정규분포를 따른다.
- 대립가설(H1): 해당 연속형 자료는 정규분포를 따르지 않는다.
② 다변수 분석
X: 범주형 / Y: 연속형

집단에 따라 연속형 데이터의 대표값(평균, 중앙값 등)에 차이가 있는지 확인
- 정규분포를 따르는 경우
  - 먼저 등분산 검정 수행
  - Bartlett Test: 집단 간 분산이 동일한지 검정
  - 등분산: 독립표본 T-test(두 집단), ANOVA(3개 이상 집단)
  - 이분산: Welch's T-test(두 집단), Welch's ANOVA(3개 이상 집단)
- 정규분포를 따르지 않는 경우
  - Mann-Whitney U Test: 두 집단 비교
  - Kruskal-Wallis Test: 3개 이상 집단 비교
  - Rank Sum Test: 순위 기반 집단 비교
X: 연속형 / Y: 연속형

두 숫자형 데이터 사이의 상관관계 확인
- 두 데이터가 정규성을 만족하는 경우
  - Pearson's Correlation Test
  - 선형적인 상관관계 측정
- 정규성을 만족하지 않거나 순위 기반 관계를 확인하는 경우
  - Spearman's Correlation Test
  - 순위 기반 상관관계 측정
X: 범주형 / Y: 범주형

두 범주형 데이터 사이에 연관성이 있는지 확인
- Chi-square Test (카이제곱 검정)
- 두 변수가 서로 독립적인지 확인
- 집단별 비율의 차이 및 연관성 분석

6. 기계학습 복습 (Machine Learning)
6-1. 기계학습의 핵심
1. 학습 능력
   - 컴퓨터가 데이터를 얼마나 잘 학습하는가?
2. 일반화 능력
   - 새로운 데이터가 들어왔을 때 얼마나 정확하게 예측하는가?
6-2. 기계학습의 3요소
1. 데이터 (특성 공학)
2. 알고리즘 (모델)
3. 하드웨어 (연산 자원 및 비용)
6-3. 기계학습의 종류
- 지도학습 (Supervised Learning)
  - 정답(Label)이 있는 데이터를 활용하여 학습
  - 분류 및 회귀 문제에 활용
- 비지도학습 (Unsupervised Learning)
  - 정답(Label)이 없는 데이터를 활용하여 패턴 및 구조 파악
  - 군집화 및 차원 축소 등에 활용
- 강화학습 (Reinforcement Learning)
  - 환경과 상호작용하면서 보상(Reward)을 최대화하도록 학습
  - 시뮬레이션 환경에서 학습 가능
- 준지도학습 (Semi-Supervised Learning)
  - 정답이 있는 데이터와 없는 데이터를 함께 활용
- 자기지도학습 (Self-Supervised Learning)
  - 데이터 자체에서 학습 목표를 만들어 학습
6-4. 지도학습 절차
1. 데이터를 학습 가능한 구조로 변환
2. 설명 변수(X)와 목표 변수(Y) 설정
3. 학습 데이터와 검증 데이터 분할
4. 학습 수행
   - 파이프라인 구축
   - 특성 공학 수행
   - 모델 학습
5. 모델 평가
6. 모델 배포
6-5. 데이터 누수와 과적합
데이터 누수 (Data Leakage)
- 목표 변수에 직접적으로 영향을 주는 정보가 설명 변수에 포함되는 경우
- 학습 데이터와 검증 데이터에 동일하거나 중복된 데이터가 포함되는 경우
- 검증 성능이 실제보다 높게 측정될 수 있음
과적합 (Overfitting)
- 학습 데이터에서는 높은 성능을 보임
- 검증 데이터에서는 성능이 낮게 나타남
- 모델이 일반적인 패턴보다 학습 데이터의 세부적인 특징이나 노이즈를 과도하게 학습한 상태
6-6. 특성 공학 (Feature Engineering)
학습 목적에 맞게 데이터를 가공하고 변환하는 작업
① Scaling & Encoding
- 숫자 데이터를 일정한 스케일로 변환
- 문자 데이터를 숫자로 변환
Scaling 종류
- MinMaxScaler
- StandardScaler
- RobustScaler
Encoding 종류
- Label Encoding
- One-Hot Encoding
② Imputation (결측치 처리)
- 데이터에 결측값이 포함된 경우 이를 처리하는 작업
- 새로운 데이터에 결측값이 포함되어도 모델이 오류 없이 처리할 수 있도록 구성
③ Cross Validation (교차 검증)
- 학습 데이터를 여러 부분으로 나누어 반복적으로 학습 및 검증
- 데이터 분할에 따른 평가 결과의 편차를 줄이고 모델의 일반화 성능을 확인
④ Hyperparameter Tuning (하이퍼파라미터 튜닝)
- 모델의 학습 구조 및 학습 과정을 사용자가 설정하여 최적화하는 작업
- 오차를 줄이고 성능을 높이는 방향으로 파라미터 탐색
대표적인 탐색 방법
- Random Search
- Grid Search
- Bayesian Search
⑤ Imbalanced Data Sampling (불균형 데이터 처리)
목표 변수의 클래스별 데이터 비율이 크게 차이 나는 경우 이를 조정하는 기법

Under Sampling
- 다수 클래스의 데이터를 줄이는 방법
- Random Under Sampling
- Tomek Links
- ENN (Edited Nearest Neighbors)
Over Sampling
- 소수 클래스의 데이터를 늘리는 방법
- Random Over Sampling
- SMOTE
- ADASYN
⑥ Feature Selection (특성 선택)
- 목표 변수에 영향을 미치는 주요 설명 변수(X)를 선택
- 불필요한 변수를 제거하여 모델의 복잡도를 낮추고 성능 개선을 기대

7. 컴퓨터 비전에서의 전이학습
7-1. 전이학습 (Transfer Learning)이란?
매우 큰 규모의 신경망을 처음부터 학습하려면 많은 데이터와 시간, 비용이 필요함.

이미 비슷한 유형의 데이터로 학습된 신경망이 있다면 해당 모델의 구조와 가중치를 가져와 재사용하는 기법
- 학습 시간 단축
- 데이터가 적은 환경에서도 활용 가능
- 기존 모델이 학습한 특징을 재사용
7-2. 전이학습의 두 가지 방식
① 특성 추출 (Feature Extraction)
- 사전학습된 모델의 Convolution 부분을 Base Model로 사용
- Base Model의 가중치를 동결(Freeze)
- Fully Connected Layer만 새롭게 학습
특징
- 학습해야 할 가중치가 적음
- 데이터가 적을 때 유리
- 일반적으로 학습 속도가 빠름
② 미세 조정 (Fine-Tuning)
- Base Model의 뒤쪽 일부 Layer를 학습 가능하도록 변경
- 낮은 학습률(Learning Rate)로 재학습
- 기존 모델의 특징을 새로운 데이터의 도메인에 맞게 조정
특징
- 기존에 학습된 가중치를 일부 수정
- 새로운 데이터에 맞게 모델 성능 개선 가능
- 학습 데이터가 충분할수록 효과적일 수 있음
전이학습 진행 순서
1. Feature Extraction
2. Fine-Tuning
두 가지 방법 중 하나만 사용하거나 순서대로 모두 사용할 수 있음.
7-3. ImageNet
- 대규모 자연 이미지 데이터셋
- 이미지 분류 모델의 사전학습에 많이 활용
- 다양한 전이학습 모델의 기반이 됨

8. ResNet 모델
8-1. ResNet이란?
ResNet (Residual Network)

2015년에 발표된 잔차 신경망으로, 깊은 신경망에서 발생하는 학습 성능 저하 문제를 해결하기 위해 개발된 모델
8-2. Gradient Vanishing (기울기 소실)
- 신경망의 Layer를 깊게 쌓을수록 역전파 과정에서 기울기가 작아지는 현상
- 앞쪽 Layer까지 학습 신호가 제대로 전달되지 않음
- 신경망이 깊어질수록 학습이 어려워질 수 있음
8-3. ResNet의 해결 방법
Skip Connection (잔차 연결)
- 입력값을 특정 Layer의 출력값에 직접 더하는 구조
- Layer가 입력값 전체를 다시 학습하는 대신 잔차(Residual)를 학습하도록 설계
- 필요한 변화량만 학습할 수 있도록 구성
- 역전파 과정에서 기울기가 전달되는 경로를 확보하여 기울기 소실 문제를 완화
핵심 원리
- 특정 Layer에서 학습할 내용이 없다면 입력값을 그대로 전달할 수 있음
- 기존 Layer의 성능을 유지하면서 추가적인 학습 수행 가능
- 깊은 신경망에서도 안정적인 학습 가능
8-4. ResNet-50
- 총 50개의 Layer로 구성된 ResNet 모델
- Bottleneck 구조를 활용하여 연산 효율 개선
- 이미지 분류 및 전이학습에 활용

9. 전이학습 모델의 종류
9-1. 최초 CNN 모델
LeNet-5 (1998년)
- CNN 기반 이미지 분류 모델의 초기 대표 사례
- 미국 수표의 숫자 인식 등에 활용
기본 구조
5x5 Convolution
→ 2x2 Pooling
→ 5x5 Convolution
→ 2x2 Pooling
→ Fully Connected Layer
→ Output


9-2. 1세대: 단순 적층 모델 (2012~)
AlexNet (2012)
- 8개의 학습 가능한 Layer로 구성된 이미지 학습 모델
- ReLU 활성화 함수 활용
- Dropout을 통한 과적합 방지
- GPU를 활용한 대규모 이미지 학습 발전에 기여
- 이미지의 엣지와 특징을 자동으로 학습
VGG16 / VGG19 (2014)
- 3x3 Convolution을 반복적으로 쌓는 단순한 CNN 구조
- 작은 필터를 여러 번 사용하여 이미지 특징 추출
- 구조가 단순하여 이해하기 쉬움
- Fully Connected Layer의 파라미터 비중이 커서 모델이 무거움
Inception (2014)
- 하나의 블록에서 여러 크기의 필터를 병렬로 적용
- 1x1 / 3x3 / 5x5 Convolution 활용
- 다양한 크기의 이미지 특징을 동시에 추출
- 연산 효율과 성능 개선
- 구조가 복잡하여 모델 튜닝이 어려울 수 있음
9-3. 2세대: 잔차 및 연결 구조 모델 (2015~)
ResNet (2015)
- Skip Connection을 활용한 잔차 학습 구조
- 깊은 신경망에서 학습 성능이 저하되는 문제 완화
- 깊은 Layer를 쌓을 수 있도록 개선
DenseNet (2016)
- 블록 내 모든 Layer의 출력을 이후 Layer에 연결
- 앞서 추출한 특징을 뒤쪽 Layer에서 재사용
- 파라미터 수 대비 높은 성능을 기대할 수 있음
- 특징을 재사용하는 연결 구조로 메모리 사용량이 클 수 있음
- 의료 영상 및 X-ray 분석에도 활용
9-4. 3세대: 경량화 모델
기존 모델의 높은 연산량을 줄여 효율적인 추론과 전이학습을 수행하기 위해 개발된 모델
MobileNet
- Depthwise Separable Convolution을 활용
- 공간적인 특징 추출과 채널 간 특징 결합을 분리하여 수행
- 연산량과 모델 크기를 줄임
- 모바일 및 실시간 이미지 처리에 적합
EfficientNet
- 깊이(Depth), 너비(Width), 입력 해상도(Resolution)를 함께 조정
- Compound Scaling 기법 활용
- 적은 파라미터로 높은 성능을 목표로 설계
- 모델 크기와 연산량 대비 효율적
- Fine-Tuning 시 학습률과 설정을 신중하게 조정해야 함
9-5. 4세대: Transformer 모델
Transformer
- 자연어 처리 분야에서 발전한 신경망 구조
- Encoder와 Decoder 구조를 기반으로 함
- Attention 메커니즘을 활용하여 데이터 간 관계를 학습
ViT (Vision Transformer, 2020)
- 이미지를 일정 크기의 Patch로 분할
- 각 Patch를 자연어의 단어처럼 취급하여 학습
- 이미지 전체의 관계를 Attention으로 학습
- CNN처럼 가까운 픽셀의 관계만 처리하지 않음
- 데이터가 적은 경우 ResNet보다 성능이 낮을 수 있음
DeiT (2021)
- Data-efficient Image Transformer
- 제한된 데이터 환경에서도 ViT를 효율적으로 학습하기 위해 개발
- 지식 증류(Knowledge Distillation)를 활용
- CNN 등 사전학습 모델의 지식을 ViT에 전달하는 방식 활용
Swin Transformer (2021)
- 이미지를 Window 단위로 나누어 Attention 수행
- 인접한 Window 간 정보를 교환
- Layer가 깊어질수록 해상도를 낮추는 계층적 구조
- 객체 검출 및 이미지 분할 등에 활용
9-6. Foundation Model (파운데이션 모델)
대규모 데이터를 활용하여 사전학습한 뒤 다양한 작업에 재사용할 수 있도록 설계된 모델
- 자기지도학습, 비지도학습, 약지도학습 등 다양한 학습 방식 활용
- 특정 작업에 한정되지 않고 여러 분야에 적용 가능
- 전이학습 및 Fine-Tuning에 활용
CLIP
- 이미지와 텍스트의 관계를 함께 학습
- 인터넷 이미지와 이미지 설명을 활용하여 학습
- 이미지 검색, 태깅, 텍스트 기반 이미지 분류 등에 활용
- 일반적인 자연 이미지에 강점
- 전문적인 의료 영상처럼 학습 데이터와 도메인이 다른 경우 성능이 떨어질 수 있음
DINO
- 라벨 없이 이미지 자체의 특징을 학습하는 자기지도학습 모델
- 동일한 이미지에서 서로 다른 형태로 변형한 데이터를 활용하여 특징 학습
- 이미지의 의미 있는 특징을 추출
- 별도의 분류기와 결합하여 이미지 분류 등에 활용
- 모델 크기와 연산량이 클 수 있음
- 도메인이 다른 데이터에서는 성능 저하 가능
SAM (Segment Anything Model)
- 이미지 내 객체를 분할하는 Foundation Model
- 사용자가 점(Point)이나 박스(Box)를 입력하면 해당 영역의 객체를 분할
- 이미지 라벨링 및 분할 데이터 구축에 활용
- 의료 영상 분야에서는 MedSAM과 같은 모델로 확장
- 자체적으로 일반적인 객체의 분류를 수행하는 모델은 아님
